# 932401.Butakov.Viktor.Lab6

Веб-приложение на Node.js и Express с поддержкой PWA

Учебный проект (Лабораторная работа №6, Вариант 1: «Приветствие с локализацией») — веб-приложение на платформе Node.js с использованием Express. Приложение предоставляет главную страницу, страницу с информацией о разработчике, API для проверки состояния сервера и генерации персонализированных приветствий на русском и английском языках. Дополнительно реализована поддержка Progressive Web App (PWA), позволяющая устанавливать приложение и использовать его в офлайн-режиме.

## Особенности проекта

**Серверная часть на Node.js и Express:** создание HTTP-сервера с использованием Express, настройка маршрутов и обработка клиентских запросов.

**Статические файлы:** раздача HTML-страниц, CSS-стилей, JavaScript-файлов, изображений и других ресурсов из директории `public` с помощью `express.static()`.

**Маршрутизация:** реализация маршрутов `/` для главной страницы, `/about` для страницы «О себе», `/api/status` для проверки состояния сервера и `/api/greet/:name` для генерации персонализированного приветствия.

**Динамические параметры URL:** получение имени пользователя из параметра маршрута `:name` и использование его при формировании ответа API.

**Локализация:** поддержка русского и английского языков с помощью query-параметра `?lang=ru`. При отсутствии параметра используется английский язык по умолчанию.

**Формирование JSON-ответов:** передача клиенту данных в формате JSON, содержащих текст приветствия, временную метку `timestamp` в формате ISO и выбранный язык `lang`.

**Валидация данных:** проверка имени пользователя на допустимые символы и длину. При некорректном имени возвращается HTTP-статус 400 и сообщение `Invalid name`.

**Обработка ошибок:** реализация обработки несуществующих маршрутов с HTTP-статусом 404 и JSON-сообщением `Not found`.

**Логирование запросов:** вывод информации о входящих HTTP-запросах в консоль сервера с указанием HTTP-метода и URL.

**Progressive Web App (PWA):** настройка манифеста `manifest.json`, указание названия приложения, режима отображения, цветовой схемы, иконок и скриншотов.

**Service Worker:** регистрация Service Worker, управление кешированием статических ресурсов и поддержка загрузки страниц в офлайн-режиме.

**Адаптивность:** поддержка различных размеров экранов благодаря CSS-стилям и метатегу `viewport`.

**Переключение тем оформления:** поддержка светлой и тёмной тем на странице «О себе» с сохранением выбранного состояния в `localStorage`.

## Используемые технологии

- **HTML5** — структура веб-страниц.
- **CSS3** — оформление и адаптивная вёрстка.
- **JavaScript** — клиентская логика и взаимодействие с DOM.
- **Node.js** — серверная среда выполнения JavaScript.
- **Express.js** — создание HTTP-сервера и настройка маршрутизации.
- **PWA** — обеспечение возможности установки приложения и офлайн-доступа.
- **Service Worker API** — кеширование ресурсов и обработка сетевых запросов.
- **Web App Manifest** — описание параметров устанавливаемого приложения.
- **localStorage** — сохранение пользовательских настроек.

## Запуск проекта

1. Установить Node.js.
2. Открыть корневую папку проекта в Visual Studio Code.
3. Установить зависимости командой:

```bash
npm install
```

4. Запустить сервер:

```bash
node server.js
```

5. Открыть приложение в браузере:

```text
http://localhost:3000
```

## Доступные маршруты

| Маршрут | Назначение |
|---|---|
| `/` | Главная страница приложения |
| `/about` | Страница «О себе» |
| `/api/status` | Проверка состояния сервера |
| `/api/greet/:name` | Генерация приветствия |
| `/api/greet/Viktor?lang=ru` | Пример приветствия на русском языке |
| `/api/greet/Viktor?lang=en` | Пример приветствия на английском языке |
